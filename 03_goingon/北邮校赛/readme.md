2026年北京高校数学建模校际联赛竞赛题目

A题  过滤设备监测
某工厂生产过程中会产生工业污水,污水排放必须达到一定的净化标准,因此需要对工业污水进行过滤处理。工厂会有若干台污水过滤器并联使用。其中透水率（permeability rate）作为对过滤器最重要的检测指标，既能反应过滤器的性能，又能反应过滤器的状态。随着过滤的进行，会有过滤物附着于过滤器的表面，以及过滤器的自然老化，使得透水率呈不断下降趋势。如果年平均透水率低于一定数值（通常是37），而且经过维护后也无法有效改善透水率的状态时，则会认为过滤器的寿命终止，需要更换新设备。为增加过滤效果并延长过滤器的使用寿命，工厂会对过滤器进行维护，根据维护方法和效果不同，分为大、中和小三种维护。小维护为日常维护，大约每3至5天会进行一次小维护。在透水率下降比较快时或者间隔时间较久时则会进行中维护。每年会对每个过滤器进行1至4次不等的大维护。维护能清除掉一些附着的污染物沉淀，使透水率增加，但也会对过滤器的性能有一定的破坏，且过滤效果以及维护效果会受到季节影响。
一台过滤器的购买价格约为300万元，一次中维护约3万元，一次大维护约为12万元，小维护成本可忽略不计。
附件1为某工厂2022年4月投用的10台过滤器在2024年4月至2026年4月的透水率检测数据。附件2为这10台过滤器2年内中维护和大维护的记录。该工厂为了尽量节省工业污水净化的年均成本，请你们团队解决以下问题：
1. 对数据进行处理，并分析数据的周期性、下降趋势和规律，以及不同维护对透水率的影响，给出反应透水率变化的影响指标。
2. 根据第1问的分析，考虑到季节对透水率的影响、过滤器的性能呈下降趋势，以及维护对过滤器性能的影响特征，按照当前的固定维护规律，构建过滤器寿命的预测模型，并给出10台过滤器的寿命预测结果。
3. 根据前两问的分析，建立数学模型，给出最优维护方案，使得工厂的污水净化年均成本最小。
4. 进一步分析：如果过滤器购买价格或者维护成本出现波动，你们所给的维护方案还是否可行？

#### 论文格式规范
来源：information/数学建模竞赛论文格式规范.doc

2026年北京高校数学建模校际联赛论文格式规范
1.  每个参赛队伍应提交的文件分为两个部分：一个是论文（PDF），一个支撑文件（压缩），如果没有用到程序代码或其他要求，可不提供支撑文件。
2.  论文A4版面, 上下左右各留出至少2.5厘米的页边距。文件格式为PDF；文件大小不超过20MB。注意参赛论文电子版文件不要压缩。
3.  论文第一页为论文标题、摘要和关键词（无需译成英文），并从此页开始编写页码；页码必须位于每页页脚中部，用阿拉伯数字从“1”开始连续编号，不要页眉。注意：摘要应该是一份简明扼要的详细摘要，请认真书写（但篇幅不能超过一页）。
4.  论文从第二页开始是论文正文；正文之后是参考文献和论文附录（页数不限）。
5. 论文附录内容应包括支撑材料的文件列表，应提供参赛者实际使用的软件名称、建模所用到的全部完整、可运行的源程序代码（含EXCEL、SPSS等软件的交互命令）等。如果缺少必要的源程序、程序不能运行或运行结果与论文不符，都可能会被取消评奖资格。如果确实没有用到程序，应在论文附录中明确说明“本论文没有用到程序”。赛题中提供的原始数据不必写入附录。
5. 支撑材料内容包括用于支撑模型、结果、结论的所有必要材料，至少应包含建模所用到的所有可运行源程序、自主查阅使用的数据资料（赛题中提供的原始数据除外）、较大篇幅中间结果的图表等。将所有支撑材料文件使用WinRAR软件压缩在一个文件中（后缀为RAR或ZIP，大小不超过20MB）。支撑材料的文件列表应放入论文附录；如果确实没有需要提供的支撑材料，可以不提供支撑材料文件，并在论文附录中注明“本论文没有支撑材料”。如果支撑材料文件与论文内容不相符，该论文可能会被取消评奖资格。所有文件中不能有显示参赛者身份和所在学校的信息, 特别注意: 支撑文件压缩包名字, 压缩包内各子文件的文件名都不允许出现学校或参赛者的任何信息。
6. 论文和附录中任何地方都不能有显示参赛者身份和所在学校的信息。
7. 引用别人的成果或其他公开的资料(包括网上资料)必须按下列方式在正文引用处和参考文献中明确列出。正文引用处用方括号标示参考文献的编号，如[1]、[3]等；引用书籍必须指出页码。参考文献按正文中的引用次序列出，其中书籍的表述方式为：
[编号] 作者，书名，出版地：出版社，出版年。
参考文献中期刊杂志论文的表述方式为：
[编号] 作者，论文名，杂志名，卷期号：起止页码，出版年。
参考文献中网上资源的表述方式为：
[编号] 作者，资源标题，网址，访问时间（年月日）。
不符合本格式规范的论文将被视为违反竞赛规则，可能被取消评奖资格。
